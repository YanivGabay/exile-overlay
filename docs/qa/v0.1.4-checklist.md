# v0.1.4 in-game check (about 5 minutes)

For Yaniv, before publishing 0.1.4. Use the test installer built from main + #10 + #12 + #13, or your installed copy once it has updated. Start Path of Exile in **Windowed** or **Windowed Fullscreen**.

Tick each line. If something looks wrong, press **F6**, click **report** on the step (or Settings → Diagnostics → **Report a problem**) and note the line number here.

## Before you log in (1 min)

1. [ ] Tray icon → Settings → **About** shows **0.1.4**. **What's new** lists 0.1.4 first: Next points, full runs from the Strand, disconnects, party and relogs, panel stacking.
2. [ ] Settings → **Setup**, with the game at the login screen:
   - With #14 in the build: a green **Connected to your game** banner, saying "At character select: log in, and the guide appears when you enter a zone."
   - Without #14: the **Game log** check is green and says "Reading …\Path of Exile\logs\LatestClient.txt" (or Client.txt).

## A fresh character (3 min)

Have a Path of Building code (or pobb.in link) ready for a leveling build of one class. Create a new character of that class (any league; Standard is fine) and log in.

3. [ ] **The Twilight Strand:** the overlay shows the banner "New character: the guide starts from the beginning." The guide card is on The Twilight Strand and the timer at the bottom of the card starts at 0:00 (Act 1).
4. [ ] Now, while in the Strand, open Settings (tray icon) → **Guide & build** → **Build (Path of Building)** and paste the code: it says "Build imported." (A build belongs to the character you're playing, so import it after logging in with the new one.)
5. [ ] **Next points** panel (left side, under the gem links) says "Next points" and, until your first level-up, "Shows up once the game log reports your level." At your resolution it must not cover the gem panel or the tree panel, and its fold tab sits clear of the panel above.
6. [ ] Kill things until **level 2**: Next points now says "you have about 1" and lists 3 passives in order, small ones with "toward <notable>" (the notable they lead to).
7. [ ] **Zone change:** walk into **Lioneye's Watch**, then **The Coast**. The guide moves to each zone by itself, no key presses.
8. [ ] **A death:** let monsters on The Coast kill you, then resurrect in town. The bottom of the guide card shows "1 death" next to the timer.
9. [ ] **Relog:** Esc → **Log out** to character select. The overlay hides. Log the same character back in: the overlay comes back on the same character, with no "New character" banner. The timer didn't count the time at character select.
10. [ ] Optional, if a friend is online: invite them and enter a zone together. When they level up, the guide stays on **your** character, and their name doesn't appear under Settings → Guide & build → **Characters**.

## Finished run and personal best (not in 5 minutes)

A run is stored when Sin says "May a new dawn arise!" after Kitava in Act 10, so this needs a full campaign. The 0.1.4 smoke test replayed your real 3.30 league start through the packaged app: it was stored as a full run (333 min, all 10 acts, 10 deaths, −30% resist).

11. [ ] On your next campaign with 0.1.4: after Kitava, the run summary says "Campaign time …: first timed run". Earlier versions stored league starts as partial runs, so 0.1.4 has no best to compare with yet. Settings → Guide & build → **Campaign runs** lists it.
12. [ ] The campaign after that says "new personal best by …" when faster (or shows "+… vs best"). The guide card shows live pace against that best while you level.

## When done

- [ ] Settings → Diagnostics → **Report a problem** copies a report: paste it somewhere private and check it has no account or character names.
- [ ] Reply "0.1.4 checklist OK" (or the failing line numbers) in the exile-overlay tab.
