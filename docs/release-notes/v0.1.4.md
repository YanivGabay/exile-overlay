# Exile Overlay 0.1.4: next passive points

If you have 0.1.1 or later, it downloads by itself and installs the next time you quit Exile Overlay (or use **Restart to update** in the tray menu).

## What's new

- **Next points.** Import your Path of Building build and a small panel shows the next three passive points to take for your level, in order, and which notable or keystone each one is heading for. If you've skipped quests that give passive points, it names them and how many points you're short, so you can go back. When your build swaps to its next tree, it tells you which points to refund. You can turn it off in Settings → Overlay.
- **Run timer fixes.** A new character's run now counts as a full run from The Twilight Strand, so campaign time, personal best and pace work on your first league start. Before, it was saved as "started mid-campaign".
- A disconnect (connection lost, realm down) hides the overlay and pauses the timer straight away, instead of up to a minute later.
- Playing in a party, a friend's level-up no longer switches the guide to their character.
- Deaths in maps after Kitava no longer add to your finished campaign's death count.
- Steadier in very long sessions: the overlay was run against more than a year of real game logs from 3.26 to 3.30 without growing in memory.

## Install

New here? Download `ExileOverlay-Setup-0.1.4.exe` below and run it. The beta isn't code-signed yet: if Windows says "Windows protected your PC", click **More info** → **Run anyway**. [Install notes](https://github.com/YanivGabay/exile-overlay/blob/main/docs/install.md).

Start Path of Exile in **Windowed** or **Windowed Fullscreen** mode.

## Known limits

- Next points follows your Path of Building trees; points from cluster jewels aren't listed.
- League tips marked "unconfirmed" aren't checked in game yet. Guide fixes download by themselves within 30 minutes, no app update needed.
- Windows only, Path of Exile 1 only. Exclusive fullscreen hides overlays (a Windows limit).
