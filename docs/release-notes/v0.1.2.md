# Exile Overlay 0.1.2: easier problem reports for 3.30 launch

A small update before the league starts. If you have 0.1.1, it downloads by itself and installs the next time you quit Exile Overlay (or use **Restart to update** in the tray menu).

## What's new

- **Report a problem** in Settings → Diagnostics copies a report (no account or character names) and opens the [bug form](https://github.com/YanivGabay/exile-overlay/issues/new?template=bug_report.yml), ready to paste.
- **Report** on a route step (press F6 in game) opens the [guide error form](https://github.com/YanivGabay/exile-overlay-guides/issues/new?template=guide_error.yml) with the zone, step and guide version filled in.
- Diagnostics links to the new [FAQ and known issues](https://github.com/YanivGabay/exile-overlay#faq-and-known-issues): the SmartScreen warning, finding Client.txt, and the overlay not showing in exclusive fullscreen.
- The error screen and the crash message offer Report a problem too.

## Install

New here? Download `ExileOverlay-Setup-0.1.2.exe` below and run it. The beta isn't code-signed yet: if Windows says "Windows protected your PC", click **More info** → **Run anyway**. [Install notes](https://github.com/YanivGabay/exile-overlay/blob/main/docs/install.md).

Start Path of Exile in **Windowed** or **Windowed Fullscreen** mode.

## Known limits

- The route data is from 3.29, with 3.30 tips from the patch notes. Zones or bosses that changed in 3.30 may be wrong for the first days; guide fixes download by themselves within 30 minutes, no app update needed.
- League tips marked "unconfirmed" aren't checked in game yet, and the 5-link drops in The Slave Pens and the Act 6 Twilight Strand may be gone in 3.30.
- Windows only, Path of Exile 1 only. Exclusive fullscreen hides overlays (a Windows limit).
