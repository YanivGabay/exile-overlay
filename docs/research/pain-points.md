# Pain points: Exile UI, exile-leveling and other PoE overlays

Research date: 2026-11-02. Link prefixes: EUI = Exile UI issues, EL = exile-leveling, APT = Awakened PoE Trade, EE2 = Exiled Exchange 2, SK = Sidekick. Read-only research; nothing was posted.

## Sources and method

- **Exile UI** (Lailloken/Exile-UI, formerly Lailloken UI, AutoHotkey v1.1): all **450** issues pulled (2022-02 to 2026-10). About 90 threads were read in full. GitHub Discussions is enabled but the maintainer runs support through Issues plus pinned `[INFO]`/`[READ]` threads ([EUI#152](https://github.com/Lailloken/Exile-UI/issues/152), [EUI#340](https://github.com/Lailloken/Exile-UI/issues/340), [EUI#547](https://github.com/Lailloken/Exile-UI/issues/547), [EUI#805](https://github.com/Lailloken/Exile-UI/issues/805)).
- **exile-leveling** (HeartofPhos, web app, 218 stars): all **66** issues pulled, about 25 read.
- **Comparison overlays** (to see which problems are shared): issue titles of Awakened PoE Trade (APT, last 1000 of its issues), Exiled Exchange 2 (EE2, all 725) and Sidekick (all 573), with the top 30 most-commented threads of each skimmed.
- **Reddit gap:** reddit.com is blocked for this agent's search and fetch tools, and Reddit mirror frontends were denied as bot-check circumvention. So **no Reddit URLs are cited**. The Reddit-sourced items below are second-hand: the maintainer or users citing Reddit inside GitHub issues. To fill this gap, a human (or a session with Reddit access) should search r/pathofexile, r/PathOfExile2 and r/pathofexilebuilds for "Exile UI", "Lailloken", "exile leveling" and "what overlays do you use".
- **Counts** come from regex over issue titles (conservative) and over titles plus bodies (upper bound). Treat them as order-of-magnitude. One issue can fall into several categories.

## Takeaways for setup and customization

1. The worst first-run failures are environmental: AHK version, folder location, config-file path, game detection and resolution. A signed native app with auto-detection plus a diagnostics screen removes roughly 40% of Exile UI's support load.
2. Pixel-based screen checks are the single biggest recurring cost: calibration, HDR, Vulkan/Win11, streaming and controller UI all break them. Prefer log, game-state and OCR signals; where pixels are needed, auto-calibrate and self-test.
3. Never modify the game window. Position everything relative to the client, per monitor and per resolution, and always clamp widgets on-screen.
4. Customization people actually ask for: free widget placement (including a 2nd monitor), compact/simplified leveling views, any-key hotkeys, toggles to keep old behaviour, no sounds, and a settings UI instead of ini edits.
5. Keep what people love: the auto-advancing act tracker with the PoB tree/gem overlay, low footprint, context-sensitive single key, an open, editable route format, and fast fixes after patches.
